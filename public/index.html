Keys

SpacePlay / stop from the cursor
1 2 3 4 (F5–F8)Play the preview length before / from the selection start, before / from the selection end
← →Move the cursor by the small step
⌥← ⌥→ (PageUp/Down)Move the cursor by the large step
⇧← ⇧→Move the cursor by one cue frame (1/75 s)
↑ ↓Cursor to selection start / end (file start / end with no selection)
[ ]Cursor to the previous / next split point and select it
, . (5 6)Move the selection by one cue frame (with ⇧: ten)
M / ⇧MMove the selected split point to the selection start / end
I O (= −)Zoom in / out (pinch also works)
0Show the whole file
⌘Z ⇧⌘ZUndo / redo split point edits
⌘SSave (only INDEX 01 lines change; a .bak is kept)
EscCancel a drag, clear the selection

Mouse / trackpad

DragSelect a range (⇧-click extends it)
ClickMove the cursor; outside the selection it also clears it
Drag a handleMove a split point (handles are the numbered marks above the waveform)
⌥-drag / right-dragMove the split point nearest to where the drag starts
↑ ↓ while draggingDrop the split point on the selection start / end
Two-finger scrollScroll; pinch to zoom
Click the overviewMove the cursor there; playback continues from it
